# swartbergcapital.com

The Swartberg Capital website, served by GitHub Pages at https://swartbergcapital.com.

Every file here is generated: the five pages, the script, the fonts and the icons by the firm's private `site/build_site.py --deploy`, and `portfolio/` by `research/quantum/vision/build.py`. Nothing is edited in this checkout by hand.

- `index.html`, `how-we-work/`, `research/`, `firm/`, `contact/`: the five pages.
- `portfolio/`: the portfolio construction figure; `portfolio/?embed` is the view the home page embeds.
- `site.js`: the embed listener on the home page.
- `fonts/`: the Archivo subset and its licence (SIL Open Font License 1.1).
- `favicon.ico`, `icon.svg`, `apple-touch-icon.png`, `og.png`: the icons and the Open Graph image.
- `CNAME`, `.nojekyll`: GitHub Pages settings.
